# V2.12 — Roadmap de refinamiento e interacción

Este documento conserva las decisiones acumuladas y marca qué parte ya está implementada.

## 1. Base del sistema — COMPLETADO
- Tokens canónicos de color, tipografía, spacing, borde, motion, z-index y responsive.
- Drift reconciliado sin borrar la personalidad de TKOH, Amazon, 20 Prod. y SUNAFIL.
- Scroll nativo, accesibilidad y reduced motion preservados.

## 2. Motion governance — FASE 1 COMPLETADA
- Motion tokens diferenciados por frecuencia/propósito.
- CSS para microinteracciones frecuentes.
- GSAP reservado para entrada editorial coordinada.
- Line traces estructurales de una sola ejecución.
- Métricas Amazon con count-up breve.
- `transition: all` prohibido y validado en 0 ocurrencias.
- Recompensas infinitas eliminadas; delight solo en eventos raros.

## 3. Explore — EN CURSO
- Comunicación / Producto / Datos cambian énfasis del portfolio.
- Click/tap/teclado soportados; hover es enhancement.
- Estado de lente ya es compartible por URL con `?lens=`.
- Estado activo no depende únicamente del color.
- Pendiente: síntesis contextual específica por lente dentro de cada caso.

## 4. Project rows — EN CURSO
- Selected Work sin preview flotante.
- Hover/focus tiene respuesta de línea, título, año y chips.
- Cada experiencia recorrida deja un check discreto en su fila.
- Pendiente: expansión inline opcional con problema, rol y CTA al caso.

## 5. Inspect — PENDIENTE
- Capturas de CR Master podrán activar un modo INSPECCIONAR.
- Hotspots accesibles explicarán jerarquía, estados, contexto y acciones.
- Keyboard/tap obligatorios; nunca hover-only.
- Mostrar criterio de diseño en vez de solo screenshots.

## 6. Connect — PENDIENTE
- Mi Sistema sigue siendo el pico visual.
- Nodos Señales / Estructura / Interfaz / Aprender ya son interactivos.
- V2.12.1 añade reveal estructural de líneas sin pinning.
- Pendiente: conectar cada nodo con proyectos y evidencia concreta.

## 7. Reward — EN CURSO
- Progreso discreto 0/4 → 4/4 implementado.
- Check dentro del documento para experiencias recorridas implementado.
- “Mapa completo” implementado con reward finito.
- Pendiente: adaptar microcopy de Contacto al recorrido/lente predominante.

## 8. Motion editorial — EN CURSO
- Titulares: mask/reveal existente.
- Datos: progresión/contador implementada para Amazon.
- Líneas: lenguaje estructural unificado implementado.
- Evidencias: reveal coordinado existente; pendiente revisar clip/reveal por tipo.
- Fotografía: movimiento mínimo.
- Evitar fade universal y animación sin significado.

## 9. Three.js — OPCIONAL / NO ACTIVADO AÚN
- Nunca usar Three.js en toda la web.
- Candidato principal: Connect / Mi Sistema / mapa espacial de perfil.
- Geometría simple, raycasting limitado, sin post-processing ni modelos pesados.
- Desktop: pointer/tap; móvil: tap y fallback.
- HTML equivalente siempre disponible.
- Solo se implementará si el prototipo supera QA de performance, accesibilidad y legibilidad.

## 10. Responsive / frontend engineering — ACTIVO
- 320 px sin scroll horizontal como contrato.
- Touch targets ~44 px.
- Ninguna acción esencial solo por hover.
- CSS estructura; JS controla estado; GSAP controla secuencias editoriales.
- Mantener densidad: evitar espacios muertos, grids arbitrarias y boxiness excesivo.

## 11. Accesibilidad — ACTIVO
- WCAG 2.2 como referencia.
- Color nunca como única señal.
- Focus visible, navegación por teclado, labels/ARIA cuando corresponda.
- Reduced motion funcional, no solo “apagar todo”.

## 12. Humanización / contenido — ACTIVO
- Español como idioma principal.
- Inglés solo para términos profesionales donde aporte precisión.
- Evitar copy genérico/promocional/de IA.
- Demostrar con evidencia antes que explicar en párrafos largos.

## 13. Cierre técnico — PENDIENTE DEPLOYMENT
- Lighthouse + Axe en URL pública.
- Core Web Vitals reales.
- Prueba táctil móvil.
- Limpieza de CSS histórico solo después de estabilizar V2.12 completa.
