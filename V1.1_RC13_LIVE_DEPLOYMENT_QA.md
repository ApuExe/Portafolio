- **Lighthouse no se reporta como ejecutado.**
- **Axe no se reporta como ejecutado.**
- **Core Web Vitals de campo no se reportan.**

Estas mediciones deben realizarse contra la URL servida desde un navegador/servicio externo con acceso de red. RC13 no introduce correcciones basadas en métricas no observadas.
