## Hallazgos del diseño

- App Rail desktop oficial: navegación directa + grupos Gestión y Crecimiento.
- Hitboxes principales documentados en Figma: 160×52 px.
- Global Search: ancho 420 px; soporta loading, results, empty y error.
- Interacción de Search documentada: flechas para navegar, Enter para abrir, Esc para cerrar.
- El prototipo incluye desktop, 1024, 768 y 390 px.
- El archivo incluye estados de filtros, Quick Create y flujos de Cliente 360 / Actividades / Oportunidades.
