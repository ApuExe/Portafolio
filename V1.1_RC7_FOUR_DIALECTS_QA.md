# V1.1 RC7 — Four Motion Dialects QA

## Scope
RC7 starts from RC6 Navigation Framing and keeps all previous mobile/nav fixes. The only product change is the stronger case choreography layer and chapter handoffs.

## Implemented motion dialects

- **TKOH / BUILD THE SYSTEM:** four-edge architectural frame, geometric product reveal, staged annotations, alternating evidence entrances, low-amplitude desktop pointer depth.
- **Amazon / FOLLOW THE SIGNAL:** sequential CAMPAÑA→DECISIÓN story activation, one-shot operational signal runner, sequential journey nodes, pointer focus on current/next step, existing metrics retained.
- **20 Prod. / EDITORIAL COMPOSITION:** alternating index entrances, editorial row focus, social pieces settling from slight rotation, low-amplitude desktop board depth.
- **SUNAFIL / HUMAN CONTEXT:** slower documentary main-image resolve, sequential verbs, delayed photo evidence, selected-photo focus with sibling quieting.
- **Shared handoff:** 01 PRODUCTO → 02 MARKETING / DATOS → 03 COMUNICACIÓN VISUAL → 04 CONTEXTO / PERSONAS → 05 MI SISTEMA / SÍNTESIS.
