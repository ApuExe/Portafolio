# V1.1 RC9 — Profile & Closing Experience QA

## Scope
Phase 3 visual/motion upgrade on top of RC8. Base Profile/Contact copy and page architecture remain unchanged.

## Profile
- Added a connected editorial thread across Comunicación → Producto → Datos.
- The thread resolves horizontally on desktop and vertically on compact layouts.
- Lens cards expose focus/hover/touch states without hiding sibling content.
- Heading, copy, current-work blocks and detail cards receive native staged entrances.
- Fine-pointer response is limited to single-digit pixel offsets.

## Contact
- Added a controlled blue/white radial light field that reacts to fine-pointer position.
- Headline, resolution, contact block and capabilities resolve in staged native motion.
- Capability cards gain focus hierarchy.
- The decorative L/S monogram gains depth without entering layout flow.
- The final vocabulary signal breathes only while Contact is visible on desktop; mobile/reduced-motion disables it.
