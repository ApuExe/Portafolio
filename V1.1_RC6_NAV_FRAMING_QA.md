# V1.1 RC6 — Main navigation framing QA

Scope: primary navigation only (`Trabajo`, `Sistema`, `Perfil`, `Contacto`).

## Root cause
The document combined global `scroll-padding-top` with per-section `scroll-margin-top`. Native anchor navigation therefore accumulated offsets and framed the outer section boundary instead of each chapter's first meaningful visual block.

## Fix
- Primary desktop/mobile nav now uses one explicit framing function.
- `Trabajo` and `Sistema` frame `.section-intro`.
- `Perfil` frames `.about-index`.
- `Contacto` preserves its intentional section-boundary framing.
- Existing case-specific anchor framing remains unchanged.
- Keyboard focus behavior remains `preventScroll` after navigation.

## Verification
Automated framing regression runs at 1584×692 and 390×844, plus the existing Contact regression and the full project test suite.
